# Job Portal Web Application

A full-stack Job Portal Web Application developed using Spring Boot, Thymeleaf, Hibernate/JPA, and MySQL.

## Features

### Candidate Module

* User Registration & Login
* View Available Jobs
* Apply for Jobs
* Save Jobs
* View Applied Jobs
* Profile Management

### Recruiter Module

* Recruiter Login
* Post New Jobs
* Manage Job Listings

## Tech Stack

* Java
* Spring Boot
* Spring MVC
* Hibernate / JPA
* Thymeleaf
* MySQL
* HTML
* CSS
* Git & GitHub

## Additional Features

* Session-based Authentication
* Role-based Access (Candidate / Recruiter)
* Responsive UI
* Job Application Status Tracking
